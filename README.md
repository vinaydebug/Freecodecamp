# FreeCodeCamp Projects Showcase

A curated collection of mini projects and exercises built while completing the FreeCodeCamp curriculum, demonstrating progressive skill development in HTML, CSS, and JavaScript.

## 📋 Overview

This repository showcases hands-on projects created as part of working through FreeCodeCamp's Responsive Web Design and front-end development courses. Each project represents practical application of web development concepts, ranging from basic HTML/CSS structures to interactive JavaScript applications.

## 🛠️ Technologies Used

- **HTML5**: Semantic markup, accessibility features
- **CSS3**: Flexbox, Grid, Animations, Responsive design
- **JavaScript**: DOM manipulation, Event handling, ES6+

## 📁 Project Structure

```
Freecodecamp-main/
├── HTML/              # Static web pages demonstrating HTML/CSS concepts
├── CSS/               # Styling-focused projects with HTML/CSS combinations
└── JAVASCRIPT/        # Interactive projects with HTML, CSS, and JavaScript
```

## 🌟 Featured Projects

### HTML Projects

These projects demonstrate progressive mastery of HTML structure and semantic elements:

1. **Recipe Page** (`HTML/project1.html`)
   - A traditional North Indian Rajma recipe page
   - Features semantic HTML5 elements (header, section, figure, figcaption)
   - Structured content with lists for ingredients and instructions

2. **Travel Agency Page** (`HTML/project2.html`)
   - Promotional page for Luxembourg tourism
   - Includes image galleries with captions
   - Demonstrates proper use of headings, paragraphs, and lists

3. **HTML Audio and Video Lab** (`HTML/project3.html`)
   - Multimedia presentation with audio and video players
   - Shows implementation of HTML5 media elements

### CSS Projects

Styling-focused projects demonstrating CSS layout techniques and visual design:

1. **Book Inventory System** (`CSS/project26/`)
   - Interactive book catalog with status tracking
   - Features:
     - Clean, readable table design with hover effects
     - Status indicators (Read, In Progress, To Read) with color coding
     - Rating visualization with CSS gradients
     - Responsive container with overflow handling
     - Custom styling for different book statuses

2. **Technical Documentation Page** (`CSS/project28/`)
   - Comprehensive documentation page modeled after MDN Web Docs
   - Features:
     - Fixed-position navigation bar with smooth scrolling
     - Responsive design that adapts to mobile devices
     - Clean typography and code formatting
     - Smooth scrolling behavior
     - Well-structured content with proper sectioning

3. **Various Mini Projects** (`CSS/project*.zip`)
   - Collection of 25+ styling exercises covering:
     - Flexbox and Grid layouts
     - Animations and transitions
     - Responsive design principles
     - Color theory and typography

### JavaScript Projects

Interactive applications demonstrating DOM manipulation and event handling:

1. **Interactive Profile Card** (`JAVASCRIPT/Interactive Profile Card/`)
   - Dynamic profile card with interactive features:
     - Theme toggle (Light/Dark mode) with smooth transitions
     - Interactive button that reveals a hidden message
     - Animated call-to-action button effects
     - Responsive design that adapts to screen size
   - Technologies:
     - DOM manipulation with vanilla JavaScript
     - CSS class toggling for theme changes
     - Event listeners for user interactions
     - CSS animations for visual feedback
