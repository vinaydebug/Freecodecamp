# FreeCodeCamp Projects

A collection of mini projects and exercises built while completing the FreeCodeCamp curriculum, focusing on HTML and CSS fundamentals.

## What's Inside

Small, hands-on projects created as part of working through FreeCodeCamp's Responsive Web Design and front-end coding exercises.

## Topics Covered

- HTML structure and semantics
- CSS styling and layouts
- Responsive design basics
- Flexbox and Grid
- Forms, tables, and media elements

## Projects

Each folder or file represents a standalone mini project or exercise — from simple page layouts to styled components.

## Purpose

Practice-driven learning. These projects reflect the progression from beginner concepts to more structured web pages.
